DRONE WORLD TOUR

가상 경기장이 아닌 브이월드의 실제 대한민국 3차원 지도를 탐험하는 드론 여행 시뮬레이터입니다. 부산 광안리에서 출발해 광안대교·해운대 해안선을 자유롭게 비행해 보세요.

01 · 키 발급브이월드에서 WebGL 3D 지도 API 인증키 발급
02 · 사이트 주소 등록인증키 발급 때 이 페이지의 웹사이트 도메인을 서비스 URL로 등록
03 · 비행 시작키 입력 후 실제 3D 지도를 불러와 조종
인증키는 공개 HTML에 내장하지 않습니다. 연결 중 탭 임시 저장소(sessionStorage)에 보관되며, 새 탭에서는 다시 입력해야 할 수 있습니다.
실행 안내: 삼성 인터넷 다운로드 주소(content://)와 로컬 파일(file://)에서는 실제 지도 연결이 제한될 수 있습니다. GitHub Pages 등 HTTPS 웹사이트에 배포한 뒤, 그 주소를 브이월드 서비스 URL로 등록하고 접속하세요.
브이월드 공식 사이트 ↗공식 3D API 코드 예제 ↗WebGL 3D API 3.0
이 파일은 웹사이트에 올린 뒤 실행해야 합니다.
1. GitHub에 새 저장소 drone-tour 생성
2. 압축 파일의 index.html을 저장소에 업로드
3. Settings → Pages → Deploy from a branch → main / root 저장
4. 생성된 실제 주소를 브이월드 인증키의 서비스 URL로 등록
5. 그 주소를 Chrome 또는 삼성 인터넷에서 직접 열기

예정 주소 예시: https://jsh5686.github.io/drone-tour/
이 URL은 저장소를 만들고 Pages 배포를 마쳐야만 유효합니다.
